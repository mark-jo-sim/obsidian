##### Alignment iteration pseudocode

Main loop:

- Iter thru alignment chunks
- For each chunk, append to current message
	- Iter thru messages within chunk if chunk spans multiple messages
- Collect span & word counts by edit type

```python
def align_transcripts(...):
	
	edit_span_count = Counter()
	edit_word_count = Counter()
	
	offsets: list[int]
	
	message_i = 0
```

Insertion helper: Only need to consider hypothesis text + timestamps

```python
def align_insertion(
	chunk: jiwer.AlignmentChunk,
	hypothesis: list[dict],
) -> dict:
	"""
	For a given insertion span, returns a message dict
	containing the start and end timestamps for the span
	as well as the text containing all inserted hypothesis
	words for that span.
	"""
	hyp_span = hypothesis[chunk.hyp_start_idx:chunk.hyp_end_idx]
	hyp_text = " ".join(word["word"] for word in hyp_span)
	start = hyp_span[0]["start"]
	end = hyp_span[-1]["end"]
	return {
		"span_type": "insert",
		"start": start,
		"end": end,
		"hyp_text": hyp_text,
	}
```

Deletion helper:

- Text comes from reference
- Trim text to message/chunk overlap
- Timestamps come from hypothesis
- Timestamps are interpolated between previous + following hypothesis words

```python
def align_deletion(
	chunk: jiwer.AlignmentChunk,
	hypothesis: list[dict],
	reference_words: list[str],
	message_start_i: int,
	message_end_i: int,
) -> dict:
	"""
	For a given deletion span, returns a message dict
	containing the start and end timestamps for the span
	as well as the text containing all deleted reference
	words for that span.
	
	Timestamps are inferred from the end of the previous
	hypothesis word and the start of the following, or
	the beginning/end of audio (if the first or last
	span in the conversation).
	
	End of audio is marked with a -1 here, to be replaced
	with the total audio duration in the main function.
	"""

	hyp_i = chunk.hyp_start_idx
	
	if hyp_i == 0:
		start = 0.0	
		end = hypothesis[hyp_i+1]["start"]
	elif hyp_i < len(hypothesis):
		start = hypothesis[hyp_i-1]["end"]
		end = hypothesis[hyp_i]["start"]
	else:
		start = hypothesis[hyp_i-1]["end"]
		end = -1
	
	ref_start = max(message_start_i, chunk.ref_start_idx)
	ref_end = min(message_end_i, chunk.ref_end_idx)
	
	ref_text = " ".join(
		reference_words[ref_start:ref_end]
	)
	
	return {
		"span_type": "deletion",
		"start": start,
		"end": end,
		"ref_text": ref_text,
	}
```

Substitution/match helper:

- Text from both reference and hypothesis
- Timestamp from hypothesis
- Trim to overlapping words btw chunk & message

```python
def align_substitution_or_match(
	chunk: jiwer.AlignmentChunk,
	hypothesis: list[dict],
	reference_words: list[str],
	message_start_i: int,
	message_end_i: int,
) -> dict:
	"""
	For a given substitution or match span, returns a message
	dict containing the start and end timestamps for the span
	as well as the text containing all matched/substiuted words
	from the reference and hypothesis for that span.
	"""
	
	ref_start = max(message_start_i, chunk.ref_start_idx)
	ref_end = min(message_end_i, chunk.ref_end_idx)
	
	start_offset = ref_start - chunk.ref_start_idx
	end_offset = chunk.ref_end_idx - ref_end
	
	hyp_start = chunk.hyp_start_idx + start_offset
	hyp_end = chunk.hyp_end_idx - end_offset
	
	ref_text = " ".join(reference_words[ref_start:ref_end])
	hyp_text = " ".join(word["word"] for word in hypothesis[hyp_start:hyp_end])
	
	start = hypothesis[hyp_start]["start"]
	end = hypothesis[hyp_end]["end"]
	
	return {
		"span_type": chunk.type,
		"start": start,
		"end": end,
		"ref_text": ref_text,
		"hyp_text": hyp_text,
	}
```
