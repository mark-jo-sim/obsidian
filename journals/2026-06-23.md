## Prepare

### Context

It would make more sense to use the existing Nemo scripts for VAD and ASR since you're going to need to do that for Forced Align anyways and I'd rather not reduplicate code in general. In order to make that migration, first we'll have to modify the map audio to transcript script such that it generates a JSONL manifest with an audio file and text for every conversation. Specifically that will have to be for every channel, which unfortunately would mean that when we want to save transcripts, we have to parse the transcript ahead of time in order to associate it with the manifest. That means that we're going to have to do the following:

1. Start by outputting a manifest that just has the audio file.
2. Run VAD and those will write to rttm files.
3. Use my own Python code to read in the ASR hypotheses and compare them to the ground truth in order to do the channel map and friends.
4. Once we have the channel map and friends decisions made, we can then map the ground truth transcripts for each audio file and update the JSONL manifest files.
5. We'll be ready to pass those JSONL manifests to Forced Align.
6. Forced Align will generate a new set of .ctm files
